# Parity deviations — metasalmonpy vs metasalmon

The mirror contract (see `AGENTS.md`) requires the same behaviour and
capabilities as metasalmon at the version this package claims — **not**
literal API mimicry. This register lists every deliberate difference; its
twin lives in the hub at `metasalmon/knowledge/parity-deviations.md`, and the
two must agree. An undocumented difference is a contract violation even when
the difference itself is fine (Brett, 2026-08-15).

Kinds of entries:

- **Idiom** — same behaviour, Pythonic delivery.
- **Ahead** — Python already has semantics R adopted later (or improved on);
  R converges or stays. Marked *converged* once metasalmon ships them; the row
  stays and keeps its number, because this package still claims an earlier
  parity milestone and the row is what tells a reader the difference is era
  lag rather than a standing choice.
- **Inapplicable** — the R behaviour has no Python counterpart, with the why.
- **Gap** — a capability metasalmon has and this package does not yet. Not an
  idiom and not a licence to stay behind: every Gap row names the milestone
  that closes it.

All four Kinds are written **one-directionally**, from metasalmon towards this
package. Row 43 is the first difference that points the other way — public
surface this package has and metasalmon never had. Whether the taxonomy gains a
fifth Kind or *Inapplicable* is read symmetrically with the direction stated in
the row is **open**; row 43's label is a placeholder saying which way it points,
not a ruling.

Row numbers are permanent in both registers so the two can be cross-referenced
by number.
