# B-59 Python documentation companion

Same-stream companion to the hub's R B-59 claim, built from Python
`origin/main` `e81cacd` under the routine draft publication grant. No second
claim or queue ID was created.

`guides/configuration.qmd` documents the actual Python schema process overrides,
retrieval flags and deprecated aliases, BioPortal key, GitHub resolution order,
separate process-local DataONE tokens, and provider-specific model/endpoint/key
fallbacks. `_quarto.yml` and `getting-started.qmd` provide navigation;
`CHANGELOG.md` records it under Unreleased.

## Source evidence and parity

Read the current implementation: `sdp_schema.py` (`set_sdp_schema_source`,
`set_sdp_schema_base_url`), `term_search.py` (`_env_flag`, private BioPortal
warning flag), `github_io.py` (`_github_token`), `knb_publication.py` (the two
DataONE token setters), and `llm_review.py` (`resolve_llm_config`).

Python already keeps BioPortal bookkeeping in private module state and uses
UUID session IDs without consuming its statistical random stream. R's
B-59 fixes therefore require no Python runtime port. Its new configuration help
requires this user-facing companion. Python's current provider path remains
available; S16 removes it in 0.7.0. This guide does not claim that S16 packet
APIs or provider deprecation warnings have landed, or import R-style options
and timeout/parallel settings.
