### What the port had to decide, and how it went

Three places where R's code does not translate word for word. Each was decided
by R's verdict, and the in-memory probe below shows the two agree.

- **Trimming.** R trims with `trimws()`, which removes spaces, tabs, carriage
  returns and line feeds. Python's `str.strip()` removes every Unicode
  whitespace character. The check uses `strip(" \t\r\n")`, so an in-memory
  `skos` ending in a no-break space is refused, as R refuses it. A value read
  from a file was already stripped by the parser, so for files the check's own
  trim changes nothing.
- **Repeated names.** R walks the `curie_map` entry by entry, so that a second
  `skos` entry in an in-memory list cannot hide behind a correct first one. A
  Python mapping holds one entry per name, so there is nothing to hide behind.
- **Shapes R reads as "no names".** A `curie_map` that is not a mapping names
  no prefix, as an unnamed one does in R, so this check passes it on and it
  fails where it is first used, as it did before. A non-string expansion is
  refused, as R refuses `NA` and a number.
