# B-302 — Port the direct LLM shortlist width and declare Frictionless

## Changed

- `semantics.py` now retains `max(max_per_role, llm_top_n)` candidates per role on the direct `suggest_semantics(llm_assess=True)` path. Without LLM assessment it retains `max_per_role`.
- `llm_review.py` shows at most `llm_top_n` of those retained candidates in the initial and retry requests, for both bundled measurement slots and other targets, without discarding the rest from deterministic suggestions.
- `pyproject.toml` declares `frictionless>=5,<6` in the optional `metasalmonpy[dwc]` extra, with the resolved dependencies in `uv.lock`. `dwc_dp_export.py` names the extra. `CHANGELOG.md` records the behavior and dependency change.

## Verification

- Before the fix, `tests/test_llm_shortlist_width.py` failed with the default direct call retaining **3** candidates rather than **5**. Its second case showed the first LLM request containing all **6** retained candidates when `llm_top_n=2`; no provider was called. The no-LLM case already passed at **3**.
- After the fix, the four focused shortlist cases and `tests/test_llm_review.py` passed: **27 passed**. The fourth case covers a non-bundle table target so the prompt cap is not measurement-only.
- Fresh core-only environment (`/tmp/b302-core-env`, `-e '.[test]'`): **1586 passed, 144 skipped, 250 subtests passed**. Fresh EML/context environment (`/tmp/b302-extras-env`, `-e '.[test,eml,context]'`): **1728 passed, 2 skipped, 291 subtests passed**. Both use Python 3.13.11 and test this worktree.
- `uv lock --check` passed; `uv run --extra dwc -- python -c 'import frictionless; print(frictionless.Package.__name__)'` printed `Package`. Frictionless 5.19.1 resolves for the package's supported Python range. The core-only environment contains no Frictionless installation.
- `python3 scripts/check-changelog-window.py` and `git diff --check` passed.
