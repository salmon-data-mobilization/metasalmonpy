## Changes

`metadata._readr_date_type()` returns `date`, `datetime` or `None` using
B-188's existing ordered column guess. `_text_reads_as_dates()` remains its
boolean wrapper, so seeding, role inference and value typing share one test.
Date shape still wins before datetime parsing; shape-only invalid calendar
dates keep B-188's readr guess and the declared-type validator is unchanged.

`dictionary._date_value_type()` recognizes pandas datetime dtype, all present
date/datetime objects, or all present text accepted by that shared guess.
Combinations containing only date/datetime objects are temporal, and any
datetime preserves the instant kind. A real readr date/instant combination
is `POSIXct`, supporting that kind choice. Mixed non-date cells cannot inherit
the first cell's date type. Explicit categorical intent is retained.

The role check remains after R's identifier-qualifier and identifier branches.
The bundled pandas-read `START_DTT` and `END_DTT` now type `date`. The public
dictionary controls use ordinary names and disable semantic seeding; the
existing B-188 token/column corpus also pins kind and role alongside codes.
`CHANGELOG.md` records the observable fix under Unreleased.
