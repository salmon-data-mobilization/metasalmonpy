### `_is_hand_picked()` on the edges

With warnings raised as errors, it returns `[]` for an empty frame with no
columns. It returns all `False` for a frame with no `source` column and for an
all-NaN float `source`. For `"user"`, `" User "`, `"USER"`, `"users"`, `pd.NA`,
`None`, `"ols"` and `""` it returns `True, True, True, False, False, False,
False, False`. On a pandas `string` column, `"user"`, a missing value and
`"smn"` give `True, False, False`. The detector
returns the empty 33-column frame for an empty table, and also for a table that
holds only a recorded row.

## Guards

The exclusion is a deliberate filter on the detector's input, so it states its
retirement condition where it is made, as R's does. It never retires, because a
recorded decision is not retrieval evidence. If a reviewer's choice should ever
count as a gap signal, that would be a new `gap_detection_basis`, not this row
passing as a candidate. No suppression, skip or allowlist was added.
