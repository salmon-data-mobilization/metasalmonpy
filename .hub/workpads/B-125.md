**Placement note.** R keeps both the seeder and the role heuristic in
`R/dictionary-helpers.R`, so its helper sits beside them. Python splits them —
seeder in `metadata.py`, heuristic in `dictionary.py`, and `dictionary.py`
imports `metadata.py`. The helper therefore lives in `metadata.py`: it keeps
"one decision, two consumers" with no circular import, and it keeps the
definition with the seeder, which is what the Q29 ruling asked for.

## Findings that are not this item

* **Filed as hub B-188** (icebox, metasalmon `155378a`): the code-row seeder accepts a date-like *object*
  column, where R's cannot.** R's seeder selects on
  `inherits(v, "factor") || inherits(v, "character")`, so a `readr`-parsed
  `Date` never reaches it. This package's seeder tests
  `is_object_dtype or is_string_dtype or CategoricalDtype`, and a pandas column
  of dates is **object** dtype whether it arrives as strings from
  `pandas.read_csv` or as `datetime.date` after parsing. So `START_DTT` and
  `END_DTT` are seeded, and the temporal branch — which runs ahead of the
  code-list check in both implementations — types them `temporal`. The result
  is two `codes.csv` rows targeting a non-categorical column, which R does not
  produce on the same example.

  **Not B-125's**, on three separate grounds, and measured rather than argued:
  it is present unchanged on the pristine tree, so this port neither caused nor
  widened it; B-125's `retires_when` names a column typed *attribute*, and
  these are typed *temporal*; and the fix is in the seeder's dtype test, which
  is the one part of the seeder the Q29 ruling deliberately left alone. Worth
  an item: it is a real divergence in shipped output for the documented Python
  workflow (`pandas.read_csv` then `create_sdp()`).

  *(This bullet read "Candidate (no item)" when it was written, and was
  false within the hour — B-188 was filed the same night. Corrected here
  rather than left, because `knowledge/parity-deviations.md` records three
  instances in two days of exactly that clause going stale, and this is a
  fourth. Name the item; do not write "no item exists".)*

  It is pinned, not just described, by
  `test_the_only_seeded_non_categorical_columns_are_the_known_date_residual`, so
  the residual is a named two rather than an open-ended "some".

* **Context, not a defect:** R's counterpart test reads the example with
  `readr::read_csv()`, the type-guessing reader. The Python fixture uses
  `pandas.read_csv` for the same reason. Using `read_sdp_csv()` — this package's
  all-character *metadata* reader — would hand the heuristic an all-string frame
  and silently defeat the identifier, temporal and measurement branches the test
  depends on running first. Worth stating because the wrong reader here fails
  open: the test still passes, having stopped testing the ordering.
