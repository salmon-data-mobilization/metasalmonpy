## Change

Q-63's existing ruling is implemented by shared helpers in `metadata.py`:
ASCII spaces/tabs, ASCII case for REVIEW, spaces/tabs before a colon, and
spaces/tabs removed after the colon. Cell checks consume the raw parsed value.
Whole-document guards retain the conservative serialized-text search and also
test decoded text/tail/attribute values on the already parsed XML document
with the same anchored raw predicate. This covers ASCII tabs escaped in XML
attributes without reparsing or defining another spelling.

Consumers updated: `review_console.py`, `metadata_write.py`, `dictionary.py`,
`package_io.py`, `sdp_methods.py`, `semantics.py`, `llm_review.py`'s surviving
deterministic current-slot validator, `eml.py` and `knb_publication.py`.
Review queues retain raw IRI inputs; an accept normalizes its decision once;
the writer preserves those recorded bytes. Ordinary unmarked decision trimming
is retained unless it would invent a marker. The marker-only test examples now
follow the ruled predicate and exclude dotless-i and a form-feed suffix.

Base: `feb724a2809a808c32ffad1ba0e5844b389c6012`, Python's landed B-343
shape gate. B-344 is the R counterpart. No term IRI, public signature, return
attribute, frozen column, version or parity-register row changed.
