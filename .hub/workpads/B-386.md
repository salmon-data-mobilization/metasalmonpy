## R baseline and scope

On metasalmon main `8cbeef3`, a local R call to
`.ms_context_text_from_html()` on the same snippets returned:

| HTML shape | R text |
| --- | --- |
| Uppercase document with title, head/body styles, a nested tag inside script, and visible body spans | `Visible start\nvisible middle\nvisible end` |
| Fragment with two paragraphs and a script | `Fragment one\nFragment two` |
| Head-only document with title and style, no body | `Fallback title` |
| Head followed by a paragraph, no explicit body | `Implicit body` |
| Loose title followed by a paragraph | `Visible body` |
| Explicit empty body with a head title | empty text |

document and retains the title while still excluding style. The port pins this
exception; it does **not** claim that head text is unconditionally excluded.
