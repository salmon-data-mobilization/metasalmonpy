## What changed, and where

- **`package_io.py`.** `PACKAGE_SENTINEL` is `".sdp-package"` and
  `_package_ownership_bytes()` returns `b"sdp-owned\n"`. Every use goes through
  those two names: the writer, the containment pre-check,
  `_package_managed_paths()` and `_is_owned_package_dir()`. So all four name
  only the shared file, and no per-language sentinel is written. The SDP-CSV
  fallback in `_is_owned_package_dir()` is unchanged, line for line. It gained
  a docstring, and `write_salmon_datapackage()`'s docstring now says which
  directories `overwrite=True` may replace, as metasalmon's roxygen does since
  B-113.
- **`tests/test_package_ownership_sentinel.py`**, new. It holds the twins of
  metasalmon's `tests/testthat/test-package-ownership-sentinel.R`, in the same
  order. The first pins both literals, spelled out, and that a real write puts
  those bytes on disk with no other dot-file at the root. The second shows that
  a directory holding only a hand-written `.sdp-package`, as a package
  metasalmon wrote would arrive, is owned and can be rewritten. The third is
  parametrized over both per-language names: a directory holding only one of
  them is not owned, the write is refused, and the directory is left as it was.
  The fourth checks that the managed-path inventory names only the shared file,
  and that a rewrite leaves both old sentinels byte-identical.
- **Existing tests.** `tests/test_current_workflow.py`'s layout test expects
  `.sdp-package`, and its "stale sentinel" near miss plants the shared one.
  `tests/test_package_ownership.py`'s `_package()` plants the shared one. The
  last two follow `PACKAGE_SENTINEL` and `_package_ownership_bytes()`, as
  metasalmon's equivalents in `test-package-helpers.R` follow its helpers since
  B-113. Nothing is weakened: each still asserts or plants a sentinel, now the
  right one.
- **`getting-started.qmd`** shows `.sdp-package` in the package layout. The
