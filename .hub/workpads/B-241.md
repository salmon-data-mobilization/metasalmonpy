   on a text or Categorical column.
3. **The codes path is tested: met.** The test asserts one report naming the
   unlisted value under both `strict` values, no name for a missing or blank
   value, the value missing afterwards, and no report for a fully listed
   column.

   does not convert already worked and is now tested, with no fix.

The B-55 run's candidate (`2f4d139`, local branch `local/B-55-mirror-unpushed`)
was read and not reused as it stood. It blanked inside the constructor call,

## What changed, and where

- **`dictionary.py`**
  - `_code_list_applies()` is R's guard on the codes step, `inherits(x,
    "character") || inherits(x, "factor")`. It is true for a Categorical, a
    string column, or an `object` column whose values are text, and the step
    runs only then. A column typed `integer`, `number`, `boolean` or `date`
    keeps its values, as in R. The test reads the values rather than the dtype
    alone, because the `date` value type leaves an `object` column of
    `datetime.date`, which R holds as a `Date`.
  - `_report_unlisted_code_values()` names each distinct present value the code
    list does not name, and returns the mask of listed rows. The codes step
    blanks exactly the rows the mask leaves out, before the `try`, so what is
    named is what is blanked on every path.
  - `_apply_dictionary_present()` mirrors R's
    `.ms_apply_dictionary_present()`: not missing, and not blank after trimming
    `READR_TRIM_CHARS`.
  - `_collapse_inline()` gains an optional `trunc`. It shortens a long list the
    way cli 3.6.6 does: 20 or fewer values are all named, and more keep the
    first 18, an ellipsis and the last two. The existing caller passes no
    `trunc` and is unchanged.
  - The docstring now says that unlisted values are reported, and which
    columns a code list applies to.
  - A column name the data repeats makes `result[new_name]` a DataFrame. That
    input keeps the path it always took. The guard and its retirement
    condition are below.
- **`tests/test_dictionary.py`**: `ApplyDictionaryFailureReportTests`, ten
  tests, the twin of metasalmon's `tests/testthat/test-edge-cases.R` plus the
  column-type guard.
- **`CHANGELOG.md`**: an entry under `## Unreleased` → `### Fixed`, after
  main's entries.
- **`AGENTS.md`**: the dated suite counts, in B-242's form, as that paragraph
  asks. Nothing else in the file changes.

## Guards added, and what retires them

  block's `pd.unique()`, where it used to return. *Retires when:* a repeated
  column name is refused, or read as R's `[[` reads it, meaning the first one.
