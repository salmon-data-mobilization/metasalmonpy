## Plan

- Mirror R canonical CSV authority, descriptor fallback and selected semantic
  metadata extensions. Include validated manifest-bound SSSOM literal HTTP
  references; exclude candidate/data/provenance URLs and CURIE expansion.
- Reuse existing SDP path, CSV rendering, atomic writing and redaction helpers.
  Preserve exact identifiers, UTF-8/C ordering and the five report columns.
- Use GET with redirects/30-second timeout; retry HTTP408/429/5xx and classified
  transient transport failures at most three times (0.1/0.25-second delays).
- Persist every final result before aggregate error, refusing default-output
  symlinks. No model call. HTTP success is resolution only, including fragments;
  it does not prove RDF presence or semantic suitability.
- Demonstrate missing behavior, focused offline controls, R report byte parity,
  minimum supported Python, full suite, reference documentation and diff gates.
