## Implementation

`apply_salmon_dictionary()` recognizes the ruled condition after filtering
codes to the current table and original column name. It uses the existing
missing/blank predicate, including the readr trim characters, on both fields.
If the optional `code_value` field is absent, an all-missing Series supplies
that side of the predicate. Any vocabulary-only row disables codes-derived
categories/labels and the unlisted-value report for the whole column, even
beside an enumerated code row.

Independent type coercion and categorical-role behavior remain unchanged;
the categorical role can still build categories from the observed values.
Ordinary codes, including code rows that also name a vocabulary, retain labels
and the warning/missing-value result for unlisted values. The public docstring
and development changelog describe this boundary. B-276/B-277 semantic-target
construction is outside this claim.
